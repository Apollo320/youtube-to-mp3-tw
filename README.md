\# YouTube to MP3 Downloader (繁體中文優化版)



這是一個輕量級的 YouTube 轉 MP3 下載工具，完全用 Python 打造，並特別針對繁體中文環境進行了優化。



\## ✨ 特色功能

\- 🛡️ \*\*突破阻擋\*\*：自動模擬播放器，繞過 YouTube 常見的 403 Forbidden 錯誤。

\- 📜 \*\*支援播放清單\*\*：貼上清單網址，自動幫每一首歌加上 `01 - `, `02 - ` 的整齊序號。

\- 🇹🇼 \*\*自動簡轉繁\*\*：內建 OpenCC，下載後自動將簡體字歌名轉換為漂亮的繁體中文！

\- 📂 \*\*自動歸檔\*\*：檔案會自動儲存到系統預設的「下載 (Downloads)」資料夾中。



\## 🛠️ 安裝與事前準備

1\. 確保電腦已安裝 \*\*Python\*\* 與 \*\*FFmpeg\*\*。

2\. 下載此專案，並在命令提示字元輸入以下指令安裝必要套件：

&#x20;  ```bash

&#x20;  pip install -r requirements.txt

🚀 如何使用
在終端機執行以下指令：

Bash
